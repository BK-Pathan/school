# 🏫 Hidaya Al Noor Dynamic School Website  

The **Hidaya Al Noor Dynamic School Website** is a fully responsive project built using **HTML, CSS, and JavaScript**.  
It provides a modern, interactive, and user-friendly interface for students, parents, and teachers.  

## ✨ Features  
- 🎓 **Home Page** – welcoming design with a school introduction  
- 📖 **About Section** – mission, vision, and school values  
- 📚 **Academics Section** – details of programs and courses  
- 🖼 **Gallery** – showcase of school activities and events  
- 🚌 **Tours Section** – virtual school tour for visitors  
- 💬 **Testimonials** – feedback from students & parents  
- 📱 **Fully Responsive** – adapts to desktop, tablet, and mobile devices  

## 🛠️ Tech Stack  
- **Frontend:** HTML, CSS, JavaScript  
- **Styling & Animations:** CSS transitions & effects  
- **Deployment:** GitHub Pages / Netlify
